아래 두 활동은 수업에서 제공한 예제를 바탕으로 혼자 진행한 개인 실습입니다. 예제 실행, 설정과 문구 수정, GitHub Pages 배포 및 결과 확인 과정을 정리했습니다.

## 1. Movie Lab 배포 실습

- 진행 시기: 2026년 10월
- 상태: 배포 실습 완료
- 사용한 도구: Vue 예제, Vite, GitHub Pages, GitHub Actions

### 활동 목적

수업에서 안내한 과제로 같은 영화 검색 예제를 두 가지 방식으로 배포했습니다. 컴퓨터에서 빌드한 결과물을 직접 올리는 방식과 GitHub Actions가 소스 코드를 빌드하고 배포하는 방식을 각각 실습했습니다.

### 내가 맡은 작업

- 제공된 예제를 실행하고 빌드 결과를 미리 확인했습니다.
- 첫 번째 저장소에는 빌드 결과물을 올려 배포했습니다.
- 두 번째 저장소에서는 저장소 이름에 맞게 Vite의 base 경로를 수정했습니다.
- GitHub Actions를 이용한 자동 빌드와 배포를 설정했습니다.

### 배운 점

커밋, 푸시, 배포가 어떤 순서로 이어지는지 헷갈렸습니다. 커밋은 변경 내용을 내 컴퓨터에 기록하고, 푸시는 그 기록을 GitHub 저장소로 보내는 단계입니다. 자동 배포를 설정한 저장소에서는 푸시 후 GitHub Actions가 빌드와 배포를 진행합니다. 배포 완료 여부는 Actions의 실행 결과와 실제 사이트 화면까지 확인해야 합니다.


### 확인한 결과와 다음 단계

실습 당시 두 배포 사이트에서 영화 포스터와 제목, Inception 검색 결과가 표시되는 것을 확인했습니다.

다음에는 배포 방식의 차이와 경로 설정이 필요한 이유를 학습 기록으로 정리할 계획입니다.

실습에 사용한 예제는 영화 검색을 위해 TMDB API 키를 입력하는 방식입니다.

## 2. 팀 소개 페이지 배포 실습

- 진행 시기: 2026년 10월
- 상태: 문구 수정 및 배포 실습 완료
- 사용한 도구: HTML, CSS, JavaScript 예제, Git, GitHub Pages

### 활동 목적

제공된 웹페이지 예제를 Git으로 관리하고, 수정한 내용을 공개 사이트에 반영하는 과정을 연습했습니다.

### 내가 맡은 작업

- 예제 파일로 Git 저장소를 초기화했습니다.
- 파일을 커밋하고 GitHub 저장소에 올렸습니다.
- GitHub Pages를 설정해 사이트를 공개했습니다.
- 소개 문구를 수정하고 다시 커밋·푸시했습니다.

### 확인한 결과와 다음 단계

실습 당시 응원 버튼의 숫자가 바뀌는 것과 수정한 소개 문구가 사이트에 반영되는 것을 확인했습니다. 휴대전화에서도 배포 주소에 접속했습니다.
