## 1. Movie Lab 배포 실습

- 진행 시기: 2026년 10월
- 상태: 배포 실습 완료
- 사용한 도구: Vue 예제, Vite, GitHub Pages, GitHub Actions

### 활동 목적

수업에서 안내한 과제로 같은 영화 검색 예제를 두 가지 방식으로 배포했습니다. 컴퓨터에서 빌드한 결과물을 직접 올리는 방식과 GitHub Actions가 소스 코드를 빌드하고 배포하는 방식을 각각 실습했습니다.

### 내가 맡은 작업

- 제공된 예제를 실행하고 빌드 결과를 미리 확인했습니다.
- 첫 번째 저장소에는 빌드 결과물을 올려 배포했습니다.
- 두 번째 저장소에서는 저장소 이름에 맞게 Vite의 base 경로를 수정했습니다.
- GitHub Actions를 이용한 자동 빌드와 배포를 설정했습니다.

### 배운 점

커밋, 푸시, 배포가 어떤 순서로 이어지는지 헷갈렸습니다. 커밋은 변경 내용을 내 컴퓨터에 기록하고, 푸시는 그 기록을 GitHub 저장소로 보내는 단계입니다. 자동 배포를 설정한 저장소에서는 푸시 후 GitHub Actions가 빌드와 배포를 진행합니다. 배포 완료 여부는 Actions의 실행 결과와 실제 사이트 화면까지 확인해야 합니다.


### 확인한 결과와 다음 단계

실습 당시 두 배포 사이트에서 영화 포스터와 제목, Inception 검색 결과가 표시되는 것을 확인했습니다.

배포 방식의 차이와 경로 설정이 필요한 이유를 [Movie Lab 학습 기록](/posts/movie-lab-deployment/)으로 정리했습니다.

실습에 사용한 예제는 영화 검색을 위해 TMDB API 키를 입력하는 방식입니다.

## 3. Hugo 개인 포트폴리오 제작

- 진행 시기: 2026년 11월
- 상태: 공개 후 개선 중
- 사용한 도구: Hugo, Hugo Profile, Markdown, HTML, CSS, JavaScript, GitHub Pages, GitHub Actions

### 활동 목적

수업 실습과 배포 과정에서 배운 내용을 한곳에 정리하기 위해 기존 Hugo 테마를 바탕으로 개인 포트폴리오를 구성했습니다.

### 내가 맡은 작업

- 소개, 프로젝트, 학습 기록과 연락처를 정리하고 한글 문구와 화면 스타일을 수정했습니다.
- 학습 글의 목록·이전 글·다음 글 링크와 404 페이지의 홈 이동 버튼을 추가했습니다.
- 키보드 포커스와 본문 이동 링크를 표시하고, 선택한 다크 모드가 유지되도록 수정했습니다.
- 새 학습 글을 초안으로 만드는 템플릿과 작성 안내를 추가했습니다.
- 수정한 파일을 직접 저장하고 커밋·푸시한 뒤 배포 결과를 확인했습니다.

설정과 코드 수정 방법, 글 구성에는 AI의 도움을 받았습니다. 파란색 로봇 이미지는 AI로 생성했으며, 파일 편집과 Git 명령 실행, 화면 확인은 직접 진행했습니다.

### 확인한 결과

공개 사이트에서 프로젝트 링크, 학습 글 목록과 이전·다음 글 이동, 404 페이지의 홈 이동을 확인했습니다. 키보드 포커스와 본문 이동 링크가 표시되고, 새로고침하거나 다른 페이지로 이동해도 선택한 다크 모드가 유지되는 것을 확인했습니다.
