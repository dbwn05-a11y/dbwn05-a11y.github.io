## 어떤 문제가 있었나요?

프로젝트 페이지에 배운 점을 추가하고 커밋·푸시했지만, GitHub Actions에 빨간색 실패 표시가 나타났습니다.

실행 결과를 열어 보니 build는 성공했고 deploy에서 실패했습니다. 로그에는 다음 메시지가 표시됐습니다.

`Deployment failed, try again later.`

## 무엇을 확인했나요?

- build가 성공했고 배포용 파일이 생성되어 있었습니다.
- deploy 로그에서 배포 대기 상태가 반복된 뒤 실패했습니다.
- 저장소의 Pages 설정은 GitHub Actions로 되어 있었습니다.
- 공개 사이트는 열렸지만, 새로 추가한 ‘배운 점’ 문단은 보이지 않았습니다.

사이트가 열린다는 사실만으로 최신 수정까지 배포됐다고 판단할 수 없다는 것을 알게 됐습니다.

## 어떻게 해결했나요?

처음에는 실패한 deploy 작업만 다시 실행했지만 같은 오류가 발생했습니다.

이후 `Re-run all jobs`로 빌드부터 전체 작업을 다시 실행했습니다. 이번에는 초록색 체크가 표시됐습니다.

프로젝트 페이지에서 Ctrl + Shift + R로 새로고침한 뒤, 새로 추가한 ‘배운 점’ 문단이 보이는 것까지 확인했습니다.

## 배운 점

커밋과 푸시가 완료되어도 배포는 별도로 실패할 수 있습니다. 실패 표시가 나타나면 어느 단계에서 문제가 생겼는지 로그를 확인해야 합니다.

이번에는 코드를 수정하지 않고 전체 재실행 후 배포에 성공했습니다. 다만 정확한 실패 원인은 로그만으로 확인하지 못했으므로, 코드 오류나 GitHub 전체 장애라고 단정하지 않았습니다.
