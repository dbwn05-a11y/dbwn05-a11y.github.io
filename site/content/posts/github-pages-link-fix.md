## 어떤 문제가 있었나요?

포트폴리오의 프로젝트 페이지에서 영화 검색 사이트의 배포 링크를 눌렀는데, 포트폴리오 홈 화면이 열렸습니다.

Markdown 파일에 적힌 주소는 맞았지만, 배포된 페이지에서는 링크가 다른 주소로 바뀌어 있었습니다.

## 원인은 무엇이었나요?

배포 과정에서 링크를 보정하는 코드가 같은 GitHub Pages 도메인의 다른 프로젝트 주소까지 현재 사이트의 내부 경로로 처리했습니다.

파일을 찾기 위해 경로를 줄이는 과정에서 빈 경로가 만들어졌고, 이를 홈 화면으로 연결하고 있었습니다.

## 어떻게 수정했나요?

현재 사이트에서 찾을 수 없는 완전한 웹 주소는 원래 주소를 유지하도록 수정했습니다.

또한 경로 끝의 슬래시를 처리해, 경로를 나누는 과정에서 빈 항목이 생기는 문제를 수정했습니다. 실제 배포에 쓰이는 코드와 해당 코드를 생성하는 원본 파일에 모두 반영했습니다.

## 수정 후 확인

변경 사항을 커밋하고 푸시한 뒤, GitHub Actions의 배포 완료를 확인했습니다.

프로젝트 페이지에서 다음 링크를 직접 눌러 확인했습니다.

- 첫 번째 배포 화면: 영화 검색 사이트가 열렸습니다.
- 자동 배포 화면: 두 번째 영화 검색 사이트가 열렸습니다.
- 팀 소개 페이지의 배포 화면: 팀 소개 사이트가 열렸습니다.

## 배운 점

원본 파일에 주소가 올바르게 적혀 있어도, 빌드 과정에서 최종 링크가 바뀔 수 있다는 것을 알게 되었습니다.

앞으로는 배포 성공 표시뿐 아니라 실제 페이지의 링크를 눌러 목적지까지 확인하겠습니다.
